# Аналитический дашборд МСУ КР

Интерактивный дашборд на основе аналитической записки по повышению эффективности исполнительных органов местного самоуправления Кыргызской Республики.

## Запуск

```bash
cd dashboard
npm install
npm run dev
```

Сборка: `npm run build`

## Содержание

- KPI: зависимость от трансфертов (85%), собственные доходы (15%), эффект реформы 30/70 (+16 п.п.), кадровый дефицит
- Структура доходов и перераспределение единого налога / налога с продаж
- Прогноз собственных доходов до 2030 (с реформой / без)
- Международное сравнение (Эстония, Финляндия, Польша, Казахстан, Респ. Корея)
- Кадровый дефицит по направлениям
- Риски и направления реформирования
- Контекст из открытых источников Минфина / НСК (2024–2025)

## Стек

Vite · React · TypeScript · Recharts
